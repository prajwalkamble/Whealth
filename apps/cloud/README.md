# WHealthOS Platform (Cloud)

> **Status: PLANNED — not implemented.** Not part of the October 2026 MVP.

A separate future product for organisations, distinct from the consumer app.

Anticipated scope: organisation and tenant management, configurable RBAC,
security policies, data isolation guarantees, custom workflows, integrations,
API management, webhooks, audit logs, compliance controls, deployment
configuration.

Nothing here is designed yet. It is recorded so the consumer app is not
accidentally built in a way that forecloses it — chiefly by keeping tenancy an
explicit concept rather than assuming one user equals one dataset.

See [docs/architecture/cloud.md](../../docs/architecture/cloud.md).
