# Shared packages

> **Status: PLANNED — all empty.**

Reserved boundaries for code that will be shared once there is more than one
consumer. Nothing has been moved yet, deliberately: the web app is currently
the only client, and a package with one consumer is just a slower import.

`pnpm-workspace.yaml` already includes `packages/*`, so adding a real package
here needs no configuration change.
